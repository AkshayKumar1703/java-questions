#### Ques 2. What is sql database and NoSQl. When will you choose NoSQL database?
Answer 2: SQL(Relational databases)
          SQL (Relational) Databases structured databases that store data in tables with fixed rows and columns, enforcing a strict schema (predefined data structure) and maintaining strong consistency using ACID compliance.  
          * Structured data with a fixed schema(tables, rows, columns).
          * Uses SQL(Structured Query Language).
          * ACID properties(Atomicity, Consistency, Isolation, Durability).
          * Examples
          NoSQL (Non-Relational) Databases are designed to store, manage, and retrieve unstructured, semi-structured, or rapidly changing data. They are typically schema-less (or use flexible schemas) and store data in formats like JSON documents, key-value pairs, graphs, or wide columns.
            
            Key Differences:    SQL vs. NoSQL
__________________________________________________________________________________
feature 	     |  SQL Database                    |	NoSQL Database
_________________|__________________________________|______________________________
Structure	     |  Tabular (Rows/Columns)	        | Document, Key Value, Graph, Column
Scheme	         |  Rigid/Predefined	            | Dynamic/Flexible
Scaling	         | Vertical (Increase server power)	| Horizontal (Add more servers)
Data Integrity	 | Strong Acid Compliance	        | BASE (Eventual Consistency)
Querying	     | Structured Query Language (SQL)	| Varies (API/Language specific)
Examples	     | MySQL, PostgreSQL, Oracle	    | MongoDB, Cassandra, Redis
